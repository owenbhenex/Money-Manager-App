# Money-Manager-App (Lumina Money)

AI-powered personal finance manager: multimodal Quick Capture (text, voice, receipt OCR) via Google Gemini 2.5 Flash, an adaptive spending rule engine created conversationally through an AI Copilot, and a dark OLED glassmorphism dashboard backed by Supabase (PostgreSQL, Auth, RLS) and Next.js 15.

See [`docs/PRD.md`](docs/PRD.md), [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), and [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md) before making changes, and [`AGENTS.md`](AGENTS.md) for contribution rules and the build roadmap.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Standard Commands

```bash
npm run dev    # development server
npm run build  # production build
npm run lint   # linting
```
