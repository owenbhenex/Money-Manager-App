# BUG-002: "Connect Bank" entrypoint unreachable on mobile viewports (hidden at <640px)

Severity: Major        Priority: P1
Status: New            Found in: b76af41 (Phase 2)          Date: 2026-09-28
Environment: http://localhost:3100, Chromium 1234 headless, viewport 375x812 (iPhone 12/13 class)
Related test case: TC-UI-012

## Steps to reproduce
1. Open dashboard at 1440x900 -> header shows "Connect Bank" button (PASS)
2. `page.setViewportSize({width: 375, height: 812})` (or open devtools mobile view)
3. Look for any way to open the bank-connect modal / subscription detection flow

## Expected result
Per AGENTS.md >= 44x44px touch targets and Phase 2 being available on mobile (the app targets mobile capture), the bank-sync entrypoint must be reachable at phone widths — either the header button visible, a mobile nav target, or a secondary entry (e.g. from Subscriptions panel "Connect a bank" link).

## Actual result
The button carries Tailwind `hidden sm:flex`, so it is removed entirely at <640px. No alternative entrypoint exists -> on a phone the user cannot connect a bank, therefore the Subscriptions detector can never be enabled (its Detect button stays disabled with 0 institutions).

## Evidence
- Playwright: "Connect Bank visible on mobile 375px: false" — screenshot `qa-evidence/2026-09-28/07-mobile-375.png`
- Note: no horizontal scroll at 375px (that part is fine), so this is purely reachability.

## Frequency: always
Workaround: none on mobile. Desktop-only currently.
Scope/impact: all Phase 2 adoption on mobile devices; also blocks the AI subscriptions feature end-to-end for phone users.
Suspected cause (hypothesis only): copied the `hidden sm:flex` pattern from the existing "Quick Log" header button in app/page.tsx. Fix = either make the button visible with an icon-only variant at <sm (keeping >=44x44), and/or add a "Connect a bank" CTA inside SubscriptionsPanel when institutionIds is empty.
